Zerca's SIMPLSYA Grill & Restaurant

This repository contains a small, responsive single-page website for Zerca's SIMPLSYA Grill & Restaurant.

Files added:
- index.html — main website
- assets/css/styles.css — stylesheet
- assets/js/main.js — small JS for menu toggle and reservation form

How to preview locally:
1. Clone the repository
2. Open index.html in a browser, or serve with a simple static server (e.g., `npx http-server` or `python -m http.server`)

Notes:
- Images use Unsplash CDN placeholders. Replace them with your own photos by adding files to `assets/images/` and updating the `src` attributes.
- The reservation form is client-side only and shows a confirmation alert. To receive submissions, integrate with a backend or a service like Formspree.
